# SECURITY.md — review loop log

`review-contract` writes one row per loop. The log lives here rather than in
SECURITY.md, following the same reasoning as `standards-review-log.md`: that
document has never carried one, no project standard requires one, and a review
table is not what a security policy's readers open it for — this one is read by
people deciding how to report a vulnerability.

Genre is pinned `standard` on every run, so the cap is 3 loops and Q4 is not
asked.
